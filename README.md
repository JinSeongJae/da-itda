## 이 프로젝트가 존재하는 이유

국내 체류 외국인은 270만 명을 넘어섰지만, 정부 조사에서 국민 10명 중 6명은 "이주민 이웃과의 교류가 거의 없다"고 답합니다. 이주민은 충분한 가치와 재능(모국어, 요리, 문화, 생활 노하우)을 지녔음에도, 이를 이웃과 나눌 C2C 교류 인프라와 신뢰 장치가 없어 일방적 수혜자로 남거나 생활 정보에서 소외됩니다.

**다잇다**는 이주민을 "지원이 필요한 대상"이 아니라 "동네에 나눌 게 있는 이웃"으로 재정의합니다. 재능을 1:1로 교환하고, 안전하게 만나고, 지속적인 관계로 이어가는 전 과정을 앱 하나로 설계했습니다.

## 핵심 기능

| 영역 | 기능 |
|---|---|
| **매칭** | 관심사·재능 기반 AI 호환도 스코어링으로 이웃 추천 |
| **채팅·약속** | 매칭 후 채팅 → 약속 제안 → **상대방 상호 수락**으로 약속 확정 |
| **안심 만남** | AI가 실제 GPS 거리순으로 추천하는 **안심 Safe Zone**(실제 경산시 공공장소) + **QR 상호 인증** 체크인 |
| **안심인증** | 신분증을 Gemini Vision AI가 분석해 주민번호 뒷자리를 자동 마스킹, 생년월일로 미성년자 가입 차단, **운영자 승인/반려** 체계 |
| **커뮤니티** | 교류 게시판 글쓰기, 동네 소모임 만들기 — 전부 실제 백엔드 연동 |
| **컬처럴 맵** | 이주민이 동네 스팟을 자신의 시선으로 등록 → 한국인이 방문·인증하면 등록자에게 교류 포인트 적립 |
| **안전장치** | 신고 기능, 만남 전 안전 경고 체크리스트, 교류 후 매너 체크리스트 → **단짝 이웃 뱃지** 및 다이렉트 채팅 |
| **알림** | 새 메시지·약속 제안/수락/거절/체크인·인증 승인 시 실제 푸시 알림 |

## 기술 스택

```
Frontend   Expo (React Native 0.86) · Expo Router · NativeWind(Tailwind) · Zustand
Backend    Vercel Serverless Functions (Node/TypeScript) · Postgres (Supabase)
AI         Gemini API — 신분증 비전 분석·마스킹, 안전지역 추천 근거 생성
Storage    Vercel Blob (마스킹된 인증 사진, 프로필 이미지)
Auth       카카오 OAuth + JWT
Build      EAS Build (Android APK)
```

**설계 제약과 대응**: Vercel Hobby 플랜은 프로젝트당 서버 함수 12개로 제한됩니다. 기능이 늘어날 때마다 새 엔드포인트를 만드는 대신, `resource` 파라미터로 관련 기능(신원인증/신고, 커뮤니티 글/소모임/컬처럴 맵 등)을 하나의 엔드포인트에 묶는 패턴으로 비용 증가 없이 계속 기능을 확장했습니다.

## 로컬 개발

```bash
npm install
npm run start        # Expo 개발 서버
```

백엔드(`api/`)는 Vercel에 별도 배포되어 있으며, `.env`에 `EXPO_PUBLIC_BACKEND_URL` 등 환경변수가 필요합니다. `.env.example` 참고.

## 폴더 구조

```
app/          Expo Router 화면 (파일 기반 라우팅)
api/          Vercel 서버리스 함수 (백엔드)
store/        Zustand 상태 저장소
components/   화면 구성 컴포넌트
constants/    i18n, 테마, 관리자 설정 등
mocks/        정적 참고 데이터 (안심존 위치, 스킬 태그 등 — 사용자 생성 콘텐츠 아님)
types/        공용 타입 정의
```
